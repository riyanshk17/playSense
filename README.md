# PlaySense — phone-camera sports analytics (Kick MVP)

*One-line:* AI-based sports analytics that turns any phone camera into a coach.

## Goal (MVP)
Detect a kicked ball from smartphone video, compute approximate speed, launch angle and accuracy against a visible target. MVP sport: Football (kick).

## Week-1 Deliverables
- Ball detection demo video (Colab + YOLO)
- Simple trajectory overlay + speed printout
- Basic React UI (later) showing video + result

## How to run (Day-1)
1. Open colab/Ball_Detect_v1.ipynb and run cells to detect ball on kick_sample.mp4.
2. Upload your video to Colab when prompted.
